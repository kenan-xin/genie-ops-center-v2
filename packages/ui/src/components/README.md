# components

The shadcn primitives on Base UI (`@base-ui/react`). The shadcn command line writes each file here from the style in `../../components.json`, for example `npx shadcn@4.22.1 add button --cwd packages/ui`. After the command, change a file only to replace a class that the token layer does not own.

Do not put composed components, business screens or hand-written primitives here.
