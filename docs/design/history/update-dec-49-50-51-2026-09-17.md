## Where the planning docs did not give enough

1. Heading above the mixed tree. The contract names the pinned rail and the tree but no label. The shell shows CATEGORIES above the groups and OTHER above the ungrouped area. Confirm or name them.
2. Count of ungrouped solutions on the Categories page. The Other row needs a solutions count that neither `category` nor `tenant_module` carries; the design adds `ungroupedSolutionCount` to the page's data. The platform decides whether the page query returns it or the row shows modules only.
3. Holders of a switched-off module. DEC-50 does not say whether the Access column shows role holders while a module is off. The design keeps them, muted, with an Off pill, because the assignments persist.
4. The Solutions module row. Its entries carry their own category ids, so the design shows the row with no category and the picker still available; DEC-51 does not say whether the picker must be hidden for a module whose tree is dynamic.
5. Switch-off confirm copy and the audit wording are the design's; no document names them.
6. Sort order inside a category. The contract does not say; the design sorts entries by label with module and solution entries mixed.
