What is new

  • Two layouts join the six picked ones: Comparison (slide 5) and Closing (slide 8). Every variant keeps the limits of the slide rules (one title, at most one text or bullet list, at most two figures, charts, tables or images), except comparison c.
  • Every number on a slide comes from a figure, chart or table on that slide (README, Chat). So the closings and comparison c carry no number, and the comparison titles state only what their figure or charts show.
  • Each caption says when the agent picks the layout. Phase 14 can start the Slides agent prompt from these lines.
  • The data is the same fictional ledger as deck-looks. Days to pay are added for the comparison.
  • At the text limits of a slide (a title of 90 characters, a text of 280, 5 bullets of 80), both closings hold their text, and so do comparisons a and b when the label is off. Comparison c holds 3 bullets of 80 in each list.

A theme on request

  • Every deck starts in the brand default: the tenant's brand color and font, with no stored theme.
  • When a person asks for a style ("make this deck dark and minimal"), the agent stores a theme for that deck only: background, text colors, accent, fonts and layout weight. Other decks keep the brand default.
  • A theme changes values. It never changes the layouts, their boxes or the slide rules.
  • Phase 14 requirement: the save checks every text pair of a theme, 4.5:1, or 3:1 from 24 px. Today the save checks the text of each element only.
  • Fonts: a theme uses the faces that the deployment ships. Only Plus Jakarta Sans ships today, so this sample changes the weight, not the face.

PowerPoint export

  • The export draws each slide from the same boxes as the screen: 960 by 540 canvas pixels on a 10 by 5.625 inch slide.
  • It draws the panel, the rules, the ring and the list circles as shapes on each slide, as it draws the title rule today.
  • Charts and tables stay native and editable. Their colors come from the theme. A chart takes its own chart area and plot area fill, and each table cell takes its own border on each side, so both can follow the dark theme.
  • pptxgenjs 4.0.1 writes the heading and body fonts of a theme into the file, but no theme colors. So each shape and text box carries its own color.
  • PowerPoint text is bold or regular, so a theme uses only these two weights.
  • With the light layout weight, the export draws no panel rectangle, and a 1 pt line in the second rule color (#4B5563, 2.66:1 on the background) at 384 px.
  • The footer takes the logo for light backgrounds in the brand default, and the logo for dark backgrounds in the dark theme. With no logo, the footer shows the company name only (README, Theme).

Differences from deck-looks d34dfd9

  • Panel text: 88% white became solid white. On blue that is 5.17:1 instead of 4.36:1 (green 5.48 instead of 4.63, violet 7.10 instead of 5.82).
  • Slide label: 75% white became solid white. On blue that is 5.17:1 instead of 3.61:1 (green 5.48 instead of 3.79).
  • The neutral chart series: #9CA3AF (2.54:1 on white) became #8B919A (3.17:1), so the line holds 3:1 and stays apart from the accent in lightness: 1.63:1 from blue, 1.73 from green, 2.24 from violet. The two lines stay apart in grayscale and for red-green color blindness. The dark theme keeps #6B7280 (4.16:1 on its background, 1.78 to 2.51:1 from the light accents).
  • Figures use proportional digits. Tabular digits left a gap before the comma ("27 ,350"). Tables keep tabular digits.
  • Figures: weight 800 became 700, because PowerPoint has bold or regular.
  • "Figures as of" shows only on a slide with a figure, chart or table, as the export draws it today. The Priorities list no longer shows it.
  • Titles wrap in balanced lines on screen, so a title does not end on one short word at any width. PowerPoint wraps titles in its own way.
  • If the owner accepts these differences at G2, this file governs the six layouts too. Until then, deck-looks governs them.
