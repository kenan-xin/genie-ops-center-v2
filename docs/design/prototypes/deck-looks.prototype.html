PROTOTYPE: deck looks

Same in every look

  • Six slide layouts the Slides agent chooses from: Title, Big number, Chart with insight, Two figures, Table with note, Priorities list. Each stays inside today's slide rules.
  • The title is the finding, in one sentence. Numbers are big and in the brand color; the comparison number is neutral.
  • Only the customer's brand color and font. Tints are that color at 8 to 14 percent, never a made-up shade, so any brand works (switch the brand above).
  • Every shape exists in PowerPoint: solid fills, rounded rectangles, lines, text and native charts, so the export can match.
  • Charts: two series as brand color and neutral grey, a short legend, month labels that keep clear of the axis, and no source line inside the chart (the footer carries "Figures as of").
  • White text sits on the brand color only when it reaches 4.5:1; the deck's existing text check recolors it otherwise.

Default, not a limit (owner, 2026-11-15)

  • The picked look is the default: every deck starts in it, built from the customer's brand, and it must look good with no prompt at all.
  • A person can still ask for any style ("make it dark and minimal", "use our green and a serif", "playful, for an all-hands"), as Claude does for slides. The agent then changes the deck's theme (colors, fonts, background, accent, layout weight) for that deck only, and the export follows.

Not decided here

  • How the agent picks a layout per slide, and the dark background option, follow the look you pick.
