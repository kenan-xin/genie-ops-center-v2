What is fixed

  • The list never shows only check marks while the run goes. The last row is always alive: the running step, or "Thinking" between steps, or "Writing slide 6 of 9".
  • The live row has a real spinner and a time that ticks each second, so a slow step reads as slow, not stuck.
  • Repeated reads stay one row, "Reading Invoices", with "4 reads" under it, instead of a ×4 chip that vanishes.
  • Writing shows where it is: "Writing slide 6 of 9" with a 9-part bar.
  • When the answer starts, the steps fold into one line "Worked for 24s · 7 steps", which opens them again.
  • One icon column: every check, spinner and the sparkle start at the same left edge as the answer text below, and every label starts at the same edge (6wz1.113). Icons are not centered in a wider column, which pushed them right.
  • The answer is one body size; only the key figure is bold (czjw.184).
  • The header says "Working" while it runs and "Saved" after; Stop is the one square button in the composer.
  • Reduced motion: the spinner is a still dashed ring and the text does not shimmer; the time still ticks.
