- No application exists, so no test ran and no contract was exercised. The scores reflect document consistency, not a working build.

- The external chat API contract is a dated observation. Section 4 gates the streaming route on a revalidation (R-42).
- One reviewer and one mechanical checker ran once each after the integration pass.
