# followups

What this folder is for: the evidence that closes a follow-up bead of a ticket, one file or one folder for each bead, named by the bead suffix. A file, or the `index.md` of a folder, states what was run, when, and against which head.

What must not go in it: ticket scope, specifications, or a claim without a way to re-run it. If a result cannot be reproduced by a command in the repository, record why.
